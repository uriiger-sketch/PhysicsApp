# Threat model: PhysicsApp

## System

| Part | What it is | Trust |
|---|---|---|
| `physics_game_v28.html` | The Hebrew master: CSS, a loader in `<head>`, the app JS in `<script type="text/x-physics-app" id="app-js">`, plus content and simulations | Trust root (reviewed commits) |
| `physics_game_en.html` | Generated by `tools/i18n.js` from the master, `i18n/en/*.json` and `config.json` | As trusted as the translations; the build guards it |
| `index.html` | Redirect page; reads `localStorage.phys_lang` | — |
| KaTeX 0.16.9 | `cdn.jsdelivr.net/npm/katex@0.16.9/dist/` (css, js, auto-render), loaded with SRI | Integrity pinned; jsDelivr sees the visitor's IP |
| Heebo and Rubik fonts | Embedded as `data:` in `<head>` (`fonts/README.md`) | Bytes pinned in the page |
| Host | GitHub Pages: HTTPS, no custom headers, origin `uriiger-sketch.github.io` shared with the account's other Pages projects | GitHub sees IPs |
| Storage | localStorage on that origin: `phys_game_state_v2`, `phys_lang`, `phys_onboarded`, `simtip_<chapter>.<section>` | **Untrusted**: any page on the origin can write it |
| Build and CI | `tools/i18n.js` (vendored acorn), `tests/*.js` (Playwright), `.github/workflows/ci.yml` | Read-only token; actions SHA-pinned |

There is no backend, no account, no cookie, no analytics and no network call
from the app (CSP `connect-src 'none'`).

## Trust boundaries and entry points

1. **localStorage → `loadState` → `_cleanSave` → state → `render()`/innerHTML.**
   This is the main boundary. Everything read from storage is validated by
   type and bound before anything reads it, and it is escaped at the sink.
2. **URL → `_applyHash`:** a regex plus a catalogue lookup.
   **`index.html` → `phys_lang`:** an own-key lookup.
3. **Keyboard → `ps.inputs` → re-rendered value:** `_escHtml`.
4. **CDN → the page:** SRI and an exact path in the CSP. If the CDN fails,
   the app uses its offline formula renderer.
5. **Translations and config → the generated edition:**
   - the `validate()` guards;
   - `escTpl`;
   - word-only patches;
   - post-build counts of `<script`, `<style` and `<!--`;
   - `acorn.parse`.
6. **PR → CI:** `pull_request` only, read-only token, no secrets, pinned
   actions, `npm ci --ignore-scripts`.
7. **The public repository and its history:** anything ever committed is
   public. The secret grep runs in CI; the owner rotates.

## Abuse cases and their controls

| # | Abuse | Control | Test |
|---|---|---|---|
| A1 | A sibling page writes markup into the save, and it runs on every visit | `_cleanSave` types and bounds, `_escHtml` at the sinks, a re-save on render cleans storage | `check_security` §2 |
| A2 | A save with `subject:"constructor"` makes the app blank for good | `_SAVE_SUBJ` plus `hasOwnProperty` in `_validPos` | §2 |
| A3 | A prototype key pollutes objects | own keys only, `__proto__`/`constructor`/`prototype` skipped | §2 |
| A4 | A huge save makes every render slow | Bounded lists and strings (1000 keys, 32 steps, 256 characters) | §2 "bounded" |
| A5 | One bad field throws and loses all the learner's progress | `typeof` before every `RegExp.test` | §2 "honest part kept" |
| A6 | A crafted link | `_applyHash` regex plus catalogue | §4 |
| A7 | An injected script sends data away | `connect-src 'none'`, `default-src 'none'`, `form-action 'none'` | §6 |
| A8 | A swapped CDN file | SRI on all three files, an exact CSP path, and CI comparing the hashes with the npm package | static, CI |
| A9 | Third parties mining visitors (IP, Referer) | Embedded fonts; `no-referrer` | static |
| A10 | A hostile translation injects script into the edition | `tools/i18n.js` guards plus post-build invariants | CI `check`/`build` |
| A11 | A compromised action or a `latest` image steals the token | Read-only token, SHA pins, `persist-credentials: false`, no Docker | review |
| A12 | Credentials in the public history | Removed from the tree, CI secret grep, rotation by the owner | CI |
| A13 | A shared school computer reveals the previous learner | "Reset" clears progress, typed answers and the `simtip_*` record | §5 |

## Headers for a host that can set them

If the app moves to a host with response headers (Cloudflare Pages, Netlify,
or a custom domain in front of GitHub Pages), send them, and keep the
`<meta>` CSP as a fallback:

```
Content-Security-Policy: <the meta policy>; frame-ancestors 'self'
X-Frame-Options: SAMEORIGIN
Strict-Transport-Security: max-age=63072000; includeSubDomains
X-Content-Type-Options: nosniff
Referrer-Policy: no-referrer
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Resource-Policy: same-origin
Permissions-Policy: accelerometer=(self), gyroscope=(self), magnetometer=(self), screen-wake-lock=(self), camera=(), microphone=(), geolocation=(), payment=(), usb=(), serial=(), hid=(), bluetooth=(), midi=(), display-capture=(), browsing-topics=()
```

These were validated over a local server with the real page. The checks
covered:
- KaTeX;
- the print popup;
- the language switch;
- the sensor lab;
- `frame-ancestors 'self'` blocking a cross-site frame.

Two cautions:
- `accelerometer`, `gyroscope` and `screen-wake-lock` must stay `(self)`:
  the sensor lab reads DeviceMotion and holds a wake lock while it
  measures.
- Never add `upgrade-insecure-requests`: on a plain-HTTP LAN preview it
  turned the same-origin language switch into an error page, and there is
  no `http://` URL to upgrade anyway.

Clickjacking is a low risk here, but it is real. A cross-site frame of the
app shares its storage, and the reset button sits only behind `confirm()`.
`frame-ancestors` fixes it, and it needs a header. Do not add JS
frame-busting.

The custom domain also ends the shared-origin storage risk (A1–A5). Progress
is kept per origin, so plan a one-time export and import.
